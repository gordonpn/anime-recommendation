# Implementation Plan — Completed Show Grouping & Multi-Signal Recommendation Ranking

This plan enhances the recommendation engine by grouping completed shows belonging to the same franchise, using the user's own rating of completed shows to scale recommendation contributions, and factoring in the franchise-wide average rating of recommended candidates.

## User Review Required

> [!IMPORTANT]
> **Key Enhancements**
> 1. **Completed Show Grouping:** Watched seasons/parts of the same series are grouped into connected components using MAL `related_anime` relations. The group uses a representative title selected via the highest popularity heuristic.
> 2. **User Rating Boost/Penalty:** Recommendations generated by a completed show/group are scaled by a multiplier: `userScore / 7.0` (using `1.0` if unrated). This allows shows you rated higher to strongly influence recommended candidates.
> 3. **Recommended Franchise-Wide Rating:** Instead of using just the recommended candidate's own rating, we fetch details for first-degree related shows (sequels, prequels, parent/full stories) and average their `mean` scores to obtain a franchise-wide rating.
